# 🎙 Алиса v2 — локальный ассистент

**«Яндекс Алиса, но только на твоём компьютере»** — локальный мозг, GUI-чат, голос и архитектура для бесплатных веб-сервисов. Никаких подписок и облаков: **0 ₽**.

Обычные вопросы отвечает `Ollama + qwen3.5:9b`; интерфейс никогда не замирает, а каждое долгое действие показывает статус в ленте.

## Возможности

- 🪟 **GUI-окно чата** — `python alice.py` по умолчанию, тёмная тема, стриминг ответа, авто-прокрутка
- ⚡ **Быстрый холодный старт** — скрытый `ollama serve`, живые статусы с таймером, таймаут LLM 120 сек
- 🧠 **Локальный мозг** — модель ~6 ГБ помещается в 8 ГБ видеопамяти
- 💬 **Текстовый чат в консоли** — `python alice.py --text`
- 🎤 **Голосовой режим** — `python alice.py --voice`
- 🇷🇺 **Русский язык** — промпт, интерфейс и голоса заточены под русский
- 💾 **Контекст 8192 токена** — диалог не теряется через пару реплик

## Требования

- Windows 10/11
- Python 3.9+ (проверено на 3.13)
- [Ollama](https://ollama.com) 0.32
- `PySide6` и `Playwright` (уже установлены; ставятся из `requirements.txt`)
- GPU от 8 ГБ (проверено: RTX 3070 8 ГБ; на CPU тоже работает, но медленнее)
- Микрофон и колонки/наушники — для голосовых сценариев

**Проверено на:** RTX 3070 8 ГБ · Intel i5-12400 · 16 ГБ DDR4 · Windows

## Установка

### 1. Мозг (Ollama + модель)

```powershell
winget install Ollama.Ollama
ollama pull qwen3.5:9b
```

Алиса при старте сама запускает скрытый `ollama serve` и принудительно передаёт ему `OLLAMA_CONTEXT_LENGTH=8192` и `OLLAMA_FLASH_ATTENTION=1`, поэтому глобальные переменные пользователя задавать не обязательно. Запасной вариант — `ollama app.exe`, если `ollama.exe` не найден.

#### Автозагрузка Ollama при входе в Windows

Чтобы холодных стартов не было вообще:

1. `Win+R` → введи `shell:startup` → Enter.
2. Создай в открывшейся папке ярлык на `ollama app.exe` (обычно `%LOCALAPPDATA%\Programs\Ollama\ollama app.exe`).
3. Перезайди в Windows.

После этого Ollama уже поднята до запуска Алисы; скрипт просто видит `ollama.list()` и сразу готов к работе.

Запасная модель для слабого железа: `ollama pull qwen2.5-coder:7b`.

### 2. Зависимости и голосовой стек

```powershell
pip install -r requirements.txt
python -m piper.download_voices ru_RU-irina-medium
```

### 3. Запуск

```powershell
python alice.py                              # GUI-окно чата (по умолчанию)
python alice.py --text                       # текстовый чат в консоли
python alice.py --voice                      # голосовой режим
python alice.py --model qwen2.5-coder:7b     # другая модель (для любого режима)
```

### Холодный старт

При закрытой Ollama окно открывается сразу, а в ленте идут живые статусы: «Запускаю Ollama… (N c)» → «Ollama готова» → «Грузим модель, первый ответ может занять до минуты…». Ожидание сервера — до 30 сек, ответ локальной модели — до **120 сек**; по таймауту в ленте появляется красная строка «Система: …», ввод разблокируется, окно остаётся живым. Все долгие действия выполняются в `QThread`.

### Базовые команды

| Команда | Что делает |
|---|---|
| `выход` | закрыть окно / выйти из консоли или голосового режима |
| `/модель` | показать скачанные модели Ollama |
| `/модель <имя>` | переключить модель и очистить историю |
| `/статус` | версия, модель, Ollama, браузер, размер истории |

## Настройка

Переменные в начале `alice.py`:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `MODEL` | `qwen3.5:9b` | какая модель отвечает |
| `NUM_CTX` | `8192` | размер контекста диалога |
| `LLM_TIMEOUT` | `120` | таймаут ответа локальной модели |
| `WHISPER_MODEL` | `small` | точность распознавания: `small` / `medium` |
| `VOICE_NAME` | `ru_RU-irina-medium` | голос (мужской: `ru_RU-ruslan-medium`) |
| `SILENCE_S` | `1.2` | пауза в секундах = конец фразы |
| `SYSTEM` | — | характер и стиль ответов |

## Как устроено

```
Окно PySide6 / консоль / микрофон
  → автозапуск Ollama (скрытый serve, 30 с)
  → локальная модель (8k контекста, стриминг, 120 с)
  → Piper / динамики (для голоса)
```

## Браузер ассистента (настраивается один раз)

Playwright работает в отдельном профиле, чтобы не трогать личные вкладки:

- Windows: `%LOCALAPPDATA%\Alice\browser-profile`
- Linux/macOS: `~/.alice/browser-profile`

Запусти `/браузер` (или кнопку **Браузер**) — откроется вкладка DeepSeek. Один раз залогинься и закрой окно браузера. Профиль запоминает куки, поэтому больше логин не просит. Ожидание настройки — до **5 минут**.

| Команда | Что делает |
|---|---|
| `д: <вопрос>` | отправить вопрос в DeepSeek |
| кнопка **DeepSeek** | то же самое для текста в поле ввода |
| `/браузер` | открыть профиль для одноразового логина |

## Умный вопрос через DeepSeek

1. «Открываю DeepSeek…» — открывается `chat.deepseek.com` в профиле ассистента.
2. Если не залогинен — «Залогинься в окне браузера (один раз)», ожидание до **5 минут**.
3. Запрос вставляется в поле и отправляется; ответ ждём до **60 сек** с индикатором «Жду ответ DeepSeek… (N c)».
4. Капча/подтверждение — «Ответь на капчу в браузере», ожидание до **3 минут**, затем продолжение.
5. Ответ появляется в ленте как `DeepSeek: …` и уходит в историю диалога.

Ошибки сети, изменённой разметки или ненайденного поля выводятся красной строкой «Система: …», состояние браузера сбрасывается, ввод разблокируется. Все CSS/селекторы DeepSeek изолированы в одном блоке `WEB_SELECTORS` в `alice.py` — при обновлении сайта правится только он.


## Музыка VK Музыка

С этого этапа `/браузер` открывает также вкладку VK Музыки: один раз залогинься и там, профиль сохранит куки. Текстовые и голосовые команды идут через тот же профиль браузера:

| Команда | Ответ в ленте |
|---|---|
| `включи <исполнитель> [трек]` | «Ищу в VK Музыке: …» → «Включаю: Исполнитель — Трек» |
| `пауза` | «Пауза.» |
| `продолжи` | «Продолжаю.» |
| `дальше` | «Следующий трек.» |
| `выключи музыку` | «Музыка выключена.» |

Если точного совпадения нет — «Не нашёл. Ближайшие варианты: …» (топ-3). Если не залогинен — «Открой VK в окне браузера ассистента, залогинься» и ожидание до **5 минут**. Селекторы VK изолированы в `WEB_SELECTORS`; при смене разметки Алиса возвращает понятную русскую ошибку, а не падает.

Яндекс Музыка оставлена архитектурной заготовкой (`MUSIC_PROVIDERS["yandex"] = False`) и подключается позже по той же схеме.

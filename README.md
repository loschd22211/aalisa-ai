# 🎙 Алиса — локальный голосовой ассистент

**«Яндекс Алиса, но только на твоём компьютере»** — голосовой ассистент с полностью локальным мозгом. Никаких подписок и облаков: всё работает на твоём железе, **0 ₽**.

Ты говоришь вслух → `faster-whisper` распознаёт речь → локальная нейросеть отвечает (`Ollama` + `qwen3.5:9b`) → `Piper` озвучивает русским голосом.

## Возможности

- 🎤 **Голосовой режим** — вопрос голосом, ответ голосом
- 💬 **Текстовый чат** — `python alice.py --text`
- 🧠 **Полностью офлайн-мозг** — модель ~6 ГБ помещается в 8 ГБ видеопамяти
- 🇷🇺 **Русский язык** — промпт и голоса заточены под русский
- 💾 **Контекст 8192 токена** — диалог не теряется через пару реплик

## Требования

- Windows 10/11
- Python 3.9+ (проверено на 3.13)
- [Ollama](https://ollama.com)
- GPU от 8 ГБ (проверено: RTX 3070 8 ГБ; на CPU тоже работает, но медленнее)
- Микрофон и колонки/наушники

**Проверено на:** RTX 3070 8 ГБ · Intel i5-12400 · 16 ГБ DDR4 · Windows

## Установка

### 1. Мозг (Ollama + модель)

```powershell
winget install Ollama.Ollama
ollama pull qwen3.5:9b
# фикс маленького контекста (иначе ассистент забывает диалог):
[System.Environment]::SetEnvironmentVariable('OLLAMA_CONTEXT_LENGTH','8192','User')
# перезапусти Ollama после этого
```

Запасная модель для слабого железа: `ollama pull qwen2.5-coder:7b`

### 2. Голосовой стек

```powershell
pip install -r requirements.txt
python -m piper.download_voices ru_RU-irina-medium
```

### 3. Запуск

```powershell
python alice.py                              # голосовой режим
python alice.py --text                       # текстовый чат
python alice.py --model qwen2.5-coder:7b     # другая модель
```

При первом запуске скачается модель распознавания whisper `small` (~460 МБ).

## Настройка

Переменные в начале `alice.py`:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `MODEL` | `qwen3.5:9b` | какая модель отвечает |
| `NUM_CTX` | `8192` | размер контекста диалога |
| `WHISPER_MODEL` | `small` | точность распознавания: `small` / `medium` |
| `VOICE_NAME` | `ru_RU-irina-medium` | голос (мужской: `ru_RU-ruslan-medium`) |
| `SILENCE_S` | `1.2` | пауза в секундах = конец фразы |
| `SYSTEM` | — | характер и стиль ответов |

## Как устроено

```
Микрофон
  → sounddevice      запись до тишины (энергетический VAD)
  → faster-whisper   распознавание русского (CPU, int8)
  → Ollama           ответ локальной модели (8k контекста, стриминг)
  → Piper            синтез русского голоса
  → динамики
```
